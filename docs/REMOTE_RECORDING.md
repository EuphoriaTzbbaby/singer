# 用网址收集声音（远程录音）

可以。Singer 自带一个手机录音页：打开链接 → 跟着提示唱 → 录音自动保存到这台 Mac。

但有一个浏览器硬限制必须先说清楚：

> **麦克风只能在 HTTPS 或 localhost 下使用。**
> 手机通过 `http://192.168.x.x:8765` 打开时，浏览器会禁用麦克风。
> 所以跨设备录音需要一条 **HTTPS 隧道**。

---

## 方案一：同一台 Mac（最简单）

直接打开：

```
http://127.0.0.1:8765/record?token=<令牌>
```

主界面点「手机录音」可以拿到带令牌的完整链接。localhost 属于安全上下文，可以正常录音。

## 方案二：手机 / 其他电脑（推荐 Cloudflare 临时隧道）

不需要账号，一条命令生成临时 HTTPS 地址。

### 1. 安装 cloudflared

```bash
brew install cloudflared
```

### 2. 启动隧道

保持 Singer 在 `127.0.0.1:8765` 运行，另开一个终端：

```bash
cloudflared tunnel --url http://127.0.0.1:8765
```

终端会打印类似：

```
https://random-words-1234.trycloudflare.com
```

### 3. 打开录音页

1. 在本机打开 `http://127.0.0.1:8765`，点「手机录音」，复制链接。
2. 从链接里取出 `token=...` 这一段（也可以直接看 `data/record_token.txt`）。
3. 拼成下面的地址，发到手机：

```
https://random-words-1234.trycloudflare.com/record?token=<令牌>
```

4. 手机浏览器打开，填音色名、勾选授权、开始录音。

> **不要打开隧道根路径 `/`**：远程访问默认只开放录音页，管理界面会返回 403。

录完点「结束并上传」，音频会通过隧道传回本机，保存在：

```
data/voices/voice_.../dataset/original/
data/voices/voice_.../dataset/wav/
data/voices/voice_.../dataset/slices/
```

并自动生成质检报告与训练包。

### 4. 用完关掉隧道

在 cloudflared 终端按 `Ctrl+C`。临时域名随即失效。

> Cloudflare 只是转发加密流量，不保存你的音频；但流量确实经过它。
> 如果这个也不能接受，用方案三或只在同一台 Mac 上录。

## 方案三：Tailscale（更私密）

如果两台设备都装了 [Tailscale](https://tailscale.com/)，可以在 Mac 上：

```bash
tailscale serve --bg 8765
```

它会给出一个 `https://<机器名>.<你的 tailnet>.ts.net` 地址，只有你 tailnet 内的设备能访问，流量走 WireGuard，不经过第三方明文。

然后同样打开：

```
https://<机器名>.<你的 tailnet>.ts.net/record?token=<令牌>
```

## 令牌在哪里

- 文件：`data/record_token.txt`
- 启动日志：`录音页: http://127.0.0.1:8765/record?token=...`
- 主界面「手机录音」按钮会自动带上

令牌是访问录音页的唯一凭证，**不要发到公开群组**。想换令牌：删掉 `data/record_token.txt` 后重启服务。

## 远程访问边界

通过隧道（Host 不是 localhost）访问时，服务只允许：

- `GET /record?token=...`
- `POST /api/recordings`
- 录音页需要的 CSS / JS

其他路径（主界面、音色/歌曲 API、模型导入）一律返回 403，避免把管理接口暴露到公网。

如果确实需要远程管理，设置环境变量后重启：

```bash
SINGER_ALLOW_REMOTE_ADMIN=1 ./scripts/dev.sh
```

**不推荐**：这会把删除音色、导入模型等操作暴露给任何拿到隧道地址的人。

## 录音页会做什么

- 引导式提示：标准约 10 分钟（元音 → 滑音 → 音阶 → 5 首歌），轻松约 5 分钟（哼鸣 → 元音 → 说话 → 2 首简单歌）。
- 显示倒计时、总进度、麦克风电平，不会唱也能完成。
- 歌曲段落不会自动切走，唱完点「下一项」。
- 结束后自动上传；**上传立即返回，切片在后台进行**，页面会轮询状态（10 分钟录音通常 1–2 分钟）。
- 返回切片数与警告；主界面立即出现新音色。

## 支持与限制

| 项目 | 说明 |
|---|---|
| 浏览器 | Chrome / Edge / Safari 新版本；iOS Safari 输出 `.mp4`，Chrome 输出 `.webm` |
| 格式 | 服务端用 ffmpeg 统一转 WAV，无需手动转换 |
| 大小 | 单次上限 500MB（约 1 小时 MP3） |
| 屏幕 | 手机录音时请保持屏幕常亮；锁屏可能中断 |
| 网络 | 隧道断开会导致上传失败；录音本身在手机内存里，重连后可重试 |
| 处理时间 | 上传很快，切片在后台；10 分钟录音约 1–2 分钟，页面会等待并显示结果 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 点开始没反应 / 提示需要 HTTPS | 换 `https://` 链接，或在本机用 localhost |
| 麦克风权限被拒绝 | 浏览器设置里允许麦克风，刷新重试 |
| 403 录音链接无效 | 令牌不对或已更换；从主界面重新获取 |
| 上传失败 | 检查隧道是否还在运行；点「重试上传」 |
| 录到一半锁屏 | 解锁后重新录；录音数据可能已丢失 |
| 切片数为 0 | 录音太短或几乎无声；检查麦克风电平 |

## 合规

- 录音页强制勾选“本人或已授权”。
- 只把链接发给你信任的人；用完关闭隧道。
- 生成内容请标注“AI 生成 / 声音转换”。
